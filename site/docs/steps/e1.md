## 手順

<div class="tk-step" data-n="1">
<Fig src="/img/channel-map.svg" cap="チャンネル割当表。board0 が脚+頭、board1 が腕+目" />
<div class="tk-text">

### サーボを正しいチャンネルへ
**board0 (0x40, 下段)**
| ch | サーボ | ch | サーボ |
|---|---|---|---|
| 0 | FR 股ヨー | 6 | RL 股ヨー |
| 1 | FR 股ピッチ | 7 | RL 股ピッチ |
| 2 | FR 膝 | 8 | RL 膝 |
| 3 | FL 股ヨー | 9 | RR 股ヨー |
| 4 | FL 股ピッチ | 10 | RR 股ピッチ |
| 5 | FL 膝 | 11 | RR 膝 |
| 12 | 頭部ヨー (未接続で OK) | | |

**board1 (0x41, 上段)**: 0 右肩ヨー / 1 右肩ピッチ / 2 右肘 / 4 左肩ヨー / 5 左肩ピッチ / 6 左肘 / 8 右目 / 10 左目。**11〜15 は挿さない**。

A1 で貼った名前テープを頼りに挿す。プラグの GND (茶/黒) を基板の GND 列へ。

</div>
</div>

<div class="tk-step rev" data-n="2">
<Fig src="/img/servo-plug.svg" cap="赤 (+) はバスバーへ、信号と GND は PCA9685 へ" />
<div class="tk-text">

### サーボ電源の分岐
1. 脚サーボ 12 本の **赤 (+) はサーボ近くで切り分けて 6V バスバー**へ (AWG20)。PCA9685 の V+ は使わない。
2. GND はバスバーと PCA9685 の両方につながっていること (<T k="gnd" />共通)。
3. 腕・目のサーボ (電流小) もバス直結に統一。
4. 束ね方: 脚 3 本 → スパイラルチューブ → φ9 穴。腕は肩ヨー根本を避けてシャーシ前縁で 1 点固定。**全可動域で張らない**ことを最後にもう一度確認。

</div>
</div>

<div class="tk-step" data-n="3">
<Fig src="/img/led-chain.svg" cap="LED は GPIO4 → 74AHCT125 → 330Ω → LED0 → LED1 → … の数珠つなぎ" />
<div class="tk-text">

### LED (WS2812B) と DFPlayer
1. <T k="levelshift" /> の A1 に GPIO4、Y1 → 330Ω → LED0 の DIN。VCC は 5V。
2. LED の順番: 0 メインアイ (ポッド前面) → 1 右目 → 2 中央目 (省略可、飛ばして配線してもよいがその場合は index がずれるので管理者へ) → 3 左目 → 4〜7 赤ランプ大 → 8〜11 赤ランプ小。各 LED の 5V/GND は並列。
3. <T k="dfplayer" />: VCC 5V、GND、TX → GPIO16、**GPIO17 → 1kΩ → RX**。SPK1/SPK2 にボディ内スピーカー直結。microSD に `/mp3/0001.mp3` 形式で音源。

</div>
</div>

<div class="tk-step rev" data-n="4">
<Fig src="/img/i2s-wiring.svg" cap="音声 (I2S) とカメラ電源は D2 / D3 で頭部側にある線を ESP32 と 5V へつなぐだけ" />
<div class="tk-text">

### 音声・カメラ・電池監視
- <T k="i2s" />: GPIO26 → SCK/BCLK、GPIO25 → WS/LRC、GPIO33 ← マイク SD、GPIO27 → アンプ DIN。マイク 3.3V、アンプ 5V。
- カメラ: 5V/GND の 2 芯を DC-DC 5V へ。
- 電池監視: GPIO34 の分圧 (B2 で設置済み) を確認。
- 頭からの線 (目 2 系統・音声 8 芯・カメラ 2 芯) はシャーシの **7 タブ間の隙間** (最小弦長 47mm) を通す。

</div>
</div>

<div class="tk-step" data-n="5">
<Fig src="/img/powerup-order.svg" cap="全体の初通電も同じ順番で" />
<div class="tk-text">

### 全体を起動する
1. <T k="calib" /> のまま、サーボ全部を抜いて電源 ON → 6.0V / 5.0V 確認。
2. サーボを 1 本ずつ挿し、全数が中立で止まることを確認。**逆向きに動く関節は無い** (中立固定なので動かない) — 動く方向の確認は E2 で。
3. シリアルで I2C エラーが無いこと。
4. 電流: 全サーボ中立保持で 1〜2A 程度なら正常。5A を超えるならどこかが突っ張っている。
5. ESP32 はテープで仮固定。Head_Top を被せる段では頭の外へ退避させる。

</div>
</div>

<Panel type="danger" title="通電後に線を抜き差ししない">

プラグの挿抜は <b>Head_Top を外し、電源 OFF</b> で。上段 board1 の南端 4ch は空のまま。

</Panel>
