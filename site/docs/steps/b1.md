<Panel type="warn" title="8/22 の実機で起きていたこと (これを直す)">

ESP32 は起動するのに、I2C エラーが毎秒 100 回以上出続けていた。スキャナで調べると <b>0x41 しか見つからず、0x40 が無応答</b>。ファームは 2 枚 (0x40 = 脚+頭、0x41 = 腕+目) を前提にしている。つまり「A0 を閉じた基板 1 枚しかつながっていない」か「0x40 側の配線・電源に問題がある」のどちらか。

</Panel>

## 手順

<div class="tk-step" data-n="1">
<Fig src="/img/a0-jumper.svg" cap="board1 だけ A0 パッドをハンダで橋渡し。board0 は何もしない" />
<div class="tk-text">

### アドレスを決める (A0 ジャンパ)
1. 2 枚の基板の角にある **A0〜A5** のパッドを見る。
2. **board0 (脚+頭)**: 全部そのまま → <span class="tk-kv">0x40</span>。
3. **board1 (腕+目)**: **A0 の上下パッドだけ**をハンダで橋渡し → <span class="tk-kv">0x41</span>。
4. 基板の裏にマジックで「0x40 脚」「0x41 腕」と書く。
5. すでに A0 が閉じている基板が 1 枚あるなら、それを board1 にする。2 枚とも閉じていたら片方をハンダ吸い取り線で外す。

<T k="address" /> の理屈: 同じ線に 2 枚つなぐので、名前 (アドレス) が違う必要がある。

</div>
</div>

<div class="tk-step rev" data-n="2">
<Fig src="/img/i2c-bus.svg" cap="SDA/SCL/VCC/GND の 4 本を 2 枚へ並列に。V+ には何もつながない" />
<div class="tk-text">

### ESP32 と 2 枚を I2C でつなぐ
| ESP32 | → PCA9685 (2 枚とも) |
|---|---|
| GPIO21 | SDA |
| GPIO22 | SCL |
| 3V3 | VCC |
| GND | GND |

- 4 本を **両方の基板**へ。ESP32 → board0 → board1 と数珠つなぎでも、ESP32 から 2 本ずつ出しても同じ。
- I2C ヘッダは **北端 (ch0 側)** のピンだけを使う (南端に直立ピンを立てない。頭のシェルに当たる)。
- **V+ 端子台には何もつながない** (サーボ電源は別経路。[B2](/steps/b2))。

</div>
</div>

<div class="tk-step" data-n="3">
<Fig src="/img/esp32-pins.svg" cap="ESP32 の使うピン一覧。番号は基板の印字で確認する" />
<div class="tk-text">

### 両方見えるか確認する
1. ESP32 を USB でパソコンにつなぎ、<T k="serial" /> を開く (115200)。

```bash
pio device monitor -b 115200
```

2. [B3](/steps/b3) のファームが入っていれば、起動後に **I2C エラー (i2cWriteReadNonStop Error) が出なくなっている**ことを確認する。8/22 は毎秒 100 回以上出ていた。
3. まだ出るなら、`i2cdetect` 相当のスキャナで 0x40 / 0x41 の両方が見えるかを確認する (管理者に頼めば 1 分で書ける)。片方しか見えない → その基板の VCC/GND/SDA/SCL を導通チェック。

</div>
</div>

<div class="tk-step rev" data-n="4">
<Fig src="/img/pca-stack.svg" cap="下段 board0 はスタンドオフの肩で押さえ、上段 board1 を M2.5×6 で固定" />
<div class="tk-text">

### シャーシへ 2 段重ねで固定する
1. **board0 (0x40)** をシャーシ中央の縦向きボス 4 個の上に置く (穴を合わせる)。
2. <T k="standoff" /> (M2.5×16 M-F) の**オスねじ側を基板の穴に通してボスへねじ込む**。六角の肩が基板を押さえる。4 本。
3. **board1 (0x41)** をスタンドオフの上に載せ、<span class="tk-kv">M2.5×6</span> ×4 で固定。M2.5×10 は長すぎて入らない。
4. **向きの決まり (2 枚とも同じ)**: ch0 側を北 (前 = +Y)、サーボプラグ列を右 (+X)、I2C ヘッダは北端。
5. 上段の **南端 4ch (11〜15) には後でもプラグを挿さない** (頭のシェルと干渉)。

</div>
</div>

<Panel type="tip" title="ESP32 本体の置き場所">

ESP32 は当面 <b>両面テープ / マジックテープで仮止め</b>。頭の中に恒久固定できる場所が無いことが設計で確定しており、置き場所はユーザー判断待ち。歩行実験は頭シェル無しで行うので問題ない。

</Panel>
