## 手順

<div class="tk-step" data-n="1">
<Fig src="/img/esp32-pins.svg" cap="書き込みは USB 端子から。PCA9685 などをつないだままでも書き込める" />
<div class="tk-text">

### ファームを書き込む
1. ESP32 を USB でパソコンにつなぐ。Mac なら `/dev/cu.usbserial-XXXX` が現れる。
2. リポジトリの `firmware/platformio.ini` で `-DCALIBRATION_MODE` が有効 (先頭の `;` が無い) ことを確認。9/5 時点で有効になっている。
3. ターミナルで:

```bash
cd Tachikoma
pio run -d firmware -t upload
```

4. 「SUCCESS」と出れば完了 (約 45 秒)。書き込み後に ESP32 は自動でリセットされる。
5. <T k="calib" /> は「全サーボを 1500µs に固定するだけ」のモード。歩行機能は動かない。

</div>
</div>

<div class="tk-step rev" data-n="2">
<Fig src="/img/servo-neutral.svg" cap="CALIBRATION_MODE = 全チャンネルに 1500µs を出し続ける" />
<div class="tk-text">

### シリアルで起動を見る
```bash
pio device monitor -b 115200
```

起動すると次のように出る:

```
Tachikoma ready: http://192.168.4.1/ / http://tachikoma.local/
```

- `nvs_open failed: NOT_FOUND` は初回起動の警告。無視してよい。
- `i2cWriteReadNonStop Error -1` が連続で出るのは **PCA9685 が 2 枚見えていない**サイン。[B1](/steps/b1) で解決する。
- 終了は `Ctrl+C`。

</div>
</div>

<div class="tk-step" data-n="3">
<Fig src="/img/vis_wiring_frame.png" cap="Web UI は歩行・腕・目・トリム・Wi-Fi 設定をスマホから操作する画面" />
<div class="tk-text">

### スマホから Web UI を開く
1. スマホの Wi-Fi 設定で **SSID「Tachikoma」** に接続する。パスワードは `firmware/src/config.h` の `AP_PASS` (各自設定値。管理者に確認)。
2. ブラウザで <span class="tk-kv">http://192.168.4.1/</span> を開く。
3. 画面が出れば OK。<T k="calib" /> 中は歩行ボタンは効かない (サーボは中立固定)。
4. <T k="mdns" /> が効く端末なら `http://tachikoma.local/` でも開ける。

</div>
</div>

<Panel type="tip" title="通常モードに戻すとき">

歩かせる段階 ([E2](/steps/e2)) では `platformio.ini` の `-DCALIBRATION_MODE` の行頭に `;` を付けてコメントアウトし、もう一度 `pio run -d firmware -t upload`。この切り替えは管理者が行う。
