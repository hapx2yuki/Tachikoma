# P37 カラーハーネス図

依頼：Blenderで作成したハーネス図の更新・カラー表示。
P21の詳細電子部品と接続を引き継ぎ、P36 S1を追加した独立平面図。本体内の電池・基板・機構配置は変更していない。

- 脚用PCA9685のPWM0–11 → 分配基板裏面 → 表面の各サーボS。V+は接続しない。
- 電池 → XT60 → 既存主ヒューズ → 分配基板F1 → 脚12軸。専用GND電力帰路と基準GNDを表示。
- 腕UBEC、MINI560、ESP32、腕PCA9685の既存経路は維持。腕4軸割当は提案のまま。
- 基板F1の15Aは候補。主ヒューズ・線径・負荷適合・UBEC設定・実機確認は未確定。
- 電池監視・停止時扱いは保留。
- 赤=分配基板F1前、黄色=F1後の脚電源、緑=個別PWM、灰=GND。図の色は実物線色ではない。
- 98配線の端点、PWM12系統独立、XT60/主ヒューズ/F1遮断時の脚給電切断を明示グラフで検査。実物導通・電流容量は検証していない。
- 原資料のPCA/サーボコネクタ等には参考形状・未確認向きが含まれる。実物ピン配列は組立前に照合する。
