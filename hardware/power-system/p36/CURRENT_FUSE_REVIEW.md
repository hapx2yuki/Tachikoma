# 電流容量・電圧降下・ヒューズ検討

## 判定

P36は**電流評価用の試作基板**として製造データを用意した。交換ヒューズはLittelfuse **0297015.L（15A / 32V、MINI 297）**を第一候補とする。15Aという表示は基板の連続運転定格ではない。

初期評価は合計10A以下から段階的に行い、合計12A条件、片側6系統への偏り、起動ピークを別々に評価する提案。これは試験条件であって、ロボットの要求電流を10Aに変更したものではない。12台の連続実負荷・ストール電流が未測定なので、「この基板で12台を任意の負荷で駆動可能」とは判定していない。

## 根拠と計算条件

HiwonderのLD-220MG公式仕様は6～8.4V、無負荷100mA、Min Working Current 1A。最後の値を最大電流・ストール電流とは解釈しない。12/18/24/36Aは各1/1.5/2/3Aを仮定した感度分析であり、メーカー保証の要求値ではない。

- 製造指定：表裏の仕上がり4.5oz。計算厚み140µm/面は仮定で、最低保証値は製造者へ確認。
- 動力銅箔1.8mm幅/面。両面が全経路に存在し、パッド・めっき穴で接続される。
- 端子位置は固定、サーボV/GパッドØ2.2/穴Ø1.0、ヒューズパッドØ3.5/穴Ø1.7。銅箔中心断面はそれぞれ1.2mm、1.8mm相当の合計幅となる。穴を無視して1.8mm幅だけで評価しない。
- 電圧降下：導体60°C、ρ20=1.724e-8 Ωm、温度係数0.00393/K、表裏50:50、各サーボ均等負荷。枝ごとに減少する電流を区間積算。
- 電圧降下の表では穴近傍の狭い部分を余分に見込む近似を加算。接点、配線、ビアバレル、ヒューズホルダー抵抗は未算入。従って系全体の最大電圧降下の保証ではない。
- 温度スクリーニング：歴史的な外層配線式 I=0.048×ΔT^0.44×A_mil²^0.725。幅を20%減、片面へ70%偏流する感度ケース。IPC-2152適合認証でも熱解析でもない。局所狭窄を長い配線として扱う近似で、両面の熱結合・ホルダーの発熱・密閉筐体の蓄熱は解いていない。

## ヒューズの選択

Keystone3568ホルダーの公称値は30Aだが、これは基板・ハーネス全体の定格ではない。公式図面と固定配置を照合し、4穴は中心間9.9×3.41mmを維持。推奨穴1.60mmに対して現在の仕上がり穴1.70mmを保持している。現物のはんだ実装性は未検証。

15A候補のメーカー温度低減表では40°C/60°Cで12A、80°Cで11Aが目安。20A品への変更は、必要電流、配線、接点、遮断時の熱量を再評価してからとする。

15A品に20.25A（135%）が流れても、溶断時間は0.75～600秒。30A（200%）でも0.15～5秒の幅がある。瞬時に15Aで遮断する部品ではない。特に20.25Aが片側へ偏る場合の局所温度スクリーニングは約91°C上昇で、長時間過負荷の保護協調を確認済みとは扱えない。短時間のヒューズ溶断に対応できるか、メーカー曲線と実物温度で確認が必要。

データシートのI²tを全短絡条件の最大遮断エネルギーと解釈しない。電池・線材抵抗で故障電流と遮断時間は変わる。15A共通ヒューズだけでは1本の細いサーボ線の過熱を必ずしも防げない。既存の主ヒューズを残し、基板F1を電池側配線の保護として流用しない。

## 発注後に必要な確認

1. 無通電で全PWMの一対一導通、G/V/Sの取り違え、F1抜去時の電源分離を確認。
2. 現物コネクタ・ホルダーを当ててはんだ実装と抜き差しを確認。選定ヘッダははんだ付け品で、圧入仕様ではない。
3. 電流制限した評価電源と電子負荷で、均等負荷と片側負荷を段階評価。両面の銅箔、ヒューズ、ホルダー、ヘッダ、電源パッドを温度測定。
4. 12台の実負荷と起動ピークを測定し、配線電圧降下とサーボ端子電圧を確認。現物仕様が不明なまま全台ストールを試す指示ではない。
5. 実電流と筐体温度を得て連続許容電流・F1容量を確定する。電池監視・停止制御の保留は今回変更していない。
