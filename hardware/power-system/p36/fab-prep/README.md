2026-11-08 / P35端子配置を固定した試作製造データ。

**Gerberとドリルデータを作成・読戻し検査済み。JLCPCB側DFM、実物の嵌合・温度・保護協調は未確認。量産承認・12台の実運転保証を意味しません。**

## 使うファイル

- `P36_JLCPCB_PROTOTYPE_GERBER.zip`：JLCPCBの基板見積りに投入する9ファイル。実際のアップロード・注文は未実施。
- `ORDER_NOTES.md`：発注条件と製造者への確認点。
- `CURRENT_FUSE_REVIEW.md`、`CURRENT_SCREENING.csv`：銅箔とヒューズの検討。未測定の最大サーボ電流を定格として扱っていない。
- `BOM.csv`：基板、ヒューズホルダー、交換ヒューズ、はんだ付けピンヘッダの候補。
- `NETLIST.csv`、`CIRCUIT_AND_PINMAP.md`：端子の信号・電源の接続。
- `FAB_READBACK_CHECKS.json`：Gerber/ドリル読戻しによる導通・異ネット間隔・穴位置の検査結果。
- `P36_DISTRIBUTOR.blend`：端子の旧配置を維持したモデル、表裏銅箔、組立表示。
- `route_candidate.json`：mm単位の全パッド・配線・穴。`source/`は再生成用のBlenderMCPスクリプト。
- `SHA256SUMS.txt`：納品時のファイルハッシュ。

## 維持したもの

外形62.5×25.4mm、厚み1.6mm、4固定穴、全54端子のXY中心位置。既存P35の端子・部品表示121オブジェクトの位置は変更していない。ボディ・電池・PCA9685・ESP32の位置も変更していない。

## 今回設計したもの

2層、仕上がり4.5ozの銅箔。電源往復は表裏各1.8mm幅で並列、PWMは0.35mm。ヒューズパッドØ3.5mm、サーボV/GパッドØ2.2mmとして穴による狭窄を緩和。電源5×8mmパッドに各12本の層間ビアを配置。表面の電源パッドだけ露出、裏面の同位置の銅箔はレジストで被覆。

F1は交換式15Aの試作候補。PCB上のヒューズを外すと全サーボV+への電池供給が切れる。PWMとGNDのみPCA9685から受ける。サーボ電源電流はPCA9685を経由しない。

## 確認できた範囲

保存した製造データを独自パーサーで読み戻し、15ネットがそれぞれ連結、異ネット間の短絡なし、最小銅箔間隔0.34mm、穴82個（PTH78、NPTH4）、外形と端子中心が指定どおりであることを確認。保存したBlenderの基板メッシュも再読込してハッシュ一致を確認。

これは独自の図形・接続検査でありKiCad DRCやJLCDFMの合格証明ではない。一般EDAのネイティブ回路図／PCBファイルは未作成。製造データは標準Gerber RS-274XとExcellon、編集元はJSON＋BlenderMCPスクリプトである。

部品付き表示はP35の形状を引き継ぐため、選定したSamtec品の実際のピン長・コネクタ嵌合を保証する図ではない。発注フットプリントは端子中心・穴径に基づく。
