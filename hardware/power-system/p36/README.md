# P36 S1 シルク印刷追加版

最新の試作用ZIPは P36_SILK_R1_JLCPCB_PROTOTYPE.zip。従来P36から表裏のシルク印刷（GTO/GBO）のみ変更した。銅箔・レジスト・外形・穴の7ファイルは元とバイト単位で一致する。

表面：B+、B−、サーボ番号0～11、S・V+・G、S PWM、F1 FUSE、P36 S1。
裏面：PWM IN、GND、入力端子番号表 J IN MAP、P36 S1。
GはGND、SはPWM信号。GNDの2端子を含む番号表は、電源パッド側を上にした背面視の並び。裏シルクデータは製造座標へ鏡像化してあるので追加で反転しない。

文字高さ基本1.0mm、線幅0.15mm。はんだ開口・固定穴との最小間隔は表0.415mm、裏0.235mm。細かな入力ピンの間へ無理に文字を入れず、裏側の空き領域に入力端子番号表を置いた。

未確定の15Aという数値を基板へ固定印刷せず、ヒューズ位置はF1と表示した。15Aは試作候補のままで、電流容量・保護協調・製造者DFMの未検証状態は従来P36から変わらない。詳細は同梱の発注条件・電流検討資料を参照。
