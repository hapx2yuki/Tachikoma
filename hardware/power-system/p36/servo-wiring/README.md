# P36 PCA9685と脚サーボ12個の接続図

P36の保存済み端子割当から作成した論理接続図。基板、製造データ、Blenderの形状は変更していない。

- PCA9685 CH0～11のS出力を、P36 J_INの同番号へ1対1に配線。
- J_INの残り2端子は共通GND。
- 電池＋は既存の主ヒューズを経てP36の＋パッドへ、基板F1を経て12個のV＋へ。
- 電池−はP36の−パッドから12個のGNDへ。
- PCA9685のサーボV＋系統をこの給電経路に接続しない。論理VCC/I²Cの既存配線は省略表示。
- 各サーボへは3線を接続。図中の灰は共通GND、実ケーブル黒。黄はヒューズ後＋、実ケーブル赤。青はPWM、実ケーブル白。
- 図は実装配置ではない。基板のJ_INは2列×7端子で裏面から見ると左右が反転するため、実装時はP36のCIRCUIT_AND_PINMAP.mdの座標と照合する。
- 現物導通・電流容量・PWM入力閾値・最終ヒューズ容量を保証する図ではない。

PNGは閲覧用、SVGは拡大用、CONNECTIONS.csvは接続一覧。
