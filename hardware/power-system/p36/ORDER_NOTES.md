# JLCPCB 試作基板の発注条件

対象は裸基板。部品実装済みPCBAの発注データではない。THTヘッダ、ホルダー、電源線は別途はんだ実装する。BOMに存在しないLCSC番号や未確認の実装サービスは指定しない。

|項目|指定|
|---|---|
|材質|FR-4|
|外形|25.4×62.5mm（短辺×長辺）、四隅直角|
|層数|2|
|板厚|1.6mm|
|外層銅厚|仕上がり4.5oz、表裏。1oz/2ozへ置換しない|
|レジスト|緑、両面|
|シルク|白、両面|
|表面処理|鉛フリーHASLを想定。重銅条件との組合せは見積りで確認|
|穴|PTH Ø0.5×24、Ø1.0×50、Ø1.7×4。NPTH Ø3.2×4|
|最小描画線幅|PWM 0.35mm|
|最小異ネット銅箔間隔|0.34mm|
|最小アニュラーリング|0.275mm（ビア）。信号パッド0.35mm|
|レジスト開口|原寸1:1。ビアは裏側テント。電源パッド内のビア表側は露出|
|外形処理|単品ルーター加工、Vカットなし、面付けなし|

JLCPCBの公開能力表で4.5ozの線幅／間隔下限は0.3/0.3mm。銅厚の最低保証値、穴めっき厚、重銅のアニュラーリング・マスク処理は製造者確認が必要。電流計算の140µmは保守的な仮定で、メーカーが保証した最小値ではない。

|ファイル|層|

|P36.GBL|裏銅箔|
|P36.GTS|表レジスト開口|
|P36.GBS|裏レジスト開口|
|P36.GTO|表シルク|
|P36.GBO|裏シルク|

単位mm、Gerber絶対座標4.6桁、Excellonは小数点付き。左下原点。裏層ファイルは**ミラー済みではない**。JLC側で裏層に割り当てる。シルク文字のみ背面から読める向きにしている。

## DFMで確認する点

- 全9層の割当、外形25.4×62.5、PTH/NPTHの区別、ヒューズ2組の同電位パッドが接することが意図的である点。
- 電源パッドの裏側はレジストで覆い、ビア穴を裏側でテントする。樹脂充填・銅充填指定ではない。
- 4.5ozの小径ビアと密集ヘッダの実製造条件。自動チェックが補正を要求した場合、端子を移動せず原因を確認する。
- 手はんだ時にビアへはんだが吸われる可能性。濡れ・表裏導通を確認する。ビア充填を電流容量に算入しない。

## 電気・組立の未確定点

12台の最大電流、現物のサーボコネクタ定格・端子長・ピン配列、ヒューズの実機溶断協調、ハーネス線径と機械的引張対策。ヘッダは圧入用ではなく、はんだ付け品を選定している。電源は2S電池で最大8.4V、PCA VCCをこの電源に接続しない。

既存の電池直近の主ヒューズは保持する。PCB内にもヒューズ前の銅箔が約58.5mmあり、基板F1だけではそこや電池配線の短絡を保護できない。基板F1は脚用分岐の保護候補であり、腕UBECやMCUの主保護を置き換えない。
