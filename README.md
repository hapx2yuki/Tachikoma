# タチコマ歩行ロボット化プロジェクト

`TACHIKOMA.3mf` (可動フィギュアの 3D 印刷キット) を、**12 サーボで歩行し、
2 本の可動腕 (キット準拠の固定爪を持つ) を持ち、スマホから操作できる
ロボット**へ改造するプロジェクト。

**2026-09-05 第2次監査結果:** 実サーボの占有、固定部品内部、挿入経路、材料別接触、実制御とSTL変換まで検査し、再現した不具合を修正。
全STL/URDFを再生成したが、頭内収納・頭固定・首/Cabin・脚装飾・足裏支持に未解決事項があり、そのまま組立歩行できる設計とは判定していない。
本文の旧「全検証PASS」は当時の検査範囲の記録であり、組立・実機歩行の合格を示さない。
最新は[第2次監査](docs/audits/20260905-round2/README.md)と
[監査Issue #80](https://github.com/hapx2yuki/Tachikoma/issues/80)を参照。

- 意匠シェル: 元モデルを 150% で印刷 (全長 ~38cm)、印刷機は Bambu Lab X2D
- 脚: 3DOF×4 (股ヨー/股ピッチ/膝)。**全軸 20kg 級標準サーボ (DS3218 系,
  デュアルベアリング出力軸)**。骨格は新規設計、シェルを被せて外観維持
- 腕: 3DOF×2 (肩ヨー/肩ピッチ/肘 = MG90S)。手は**キット準拠の固定爪**
  (2026-07-29 可動グリッパから変更: 「爪は可動不要」というユーザー方針に
  基づき、可動グリッパ機構 [palm_base/grip_slider/grip_finger + サブ
  マイクロ×2] を廃止し、元キットの Claw_Grey [爪ハブ] + Finger_Black×3
  [指, 差込] + FingerTip_Grey×3 [指先チップ, 接着] を無加工のまま前腕終端
  の claw_mount へ接着する構成に単純化)。**実機準拠でシャーシ前縁下面から
  吊り下げ**、寸法はキット実測比率 (肘→爪直結の短い腕。3MF フォレンジクス
  実測で前腕を 24→16mm に再短縮)。**意匠は元キットパーツ**: 上腕 = Arm
  ポッドのクラムシェル被せ、肘 = Elbow 球の半殻、爪ハブ/指/指先チップは
  無加工のキット STL そのもの。プリセット TUCK/READY/REACH/WAVE + 各軸
  個別操作 (肩ヨー/肩ピッチ/肘の 3 軸のみ、グリップ軸は無し)
- 制御: ESP32 + PCA9685 ×2 (0x40 脚+頭 / 0x41 腕+目)。WiFi AP (操作UI
  フォールバック) + STA (iPhone インターネット共有へ join) + スマホブラウザ
- 歩容: 回転順クロール (RL→FL→FR→RR) + 重心シフト 前脚 34 / 後脚 40mm + 中立足先を実重心側
  (y=-39mm, Cabin が主因) へ 30mm オフセット → 実重心基準の静的安定 +10.9mm (2026-09-04)
- **目**: **元キットの目パーツ (Head_Eye_White) の形状をそのまま可動化**。
  左右 2 目は白い扁平ドームの黒ドット群 (モールド穴を黒仕上げ) がキャップ軸
  から ~45° 偏心しているため、サブマイクロ ×2 の自軸回転だけで視線が泳ぐ
  **キョロキョロ機構** (掃引径 ~28mm。ランダムサッカード/正面固定/スキャン
  の 3 モード + 歩行方向への視線バイアス)。**中央目は固定カメラ目**
  (下記「カメラ」参照, 2026-07-28 設計変更)。Head_Top の目ソケット
  (φ42.3 座グリ, STL 実測) の底へ φ30 貫通ボアを開け (Head_Top_Eyecut.stl
  生成済み)、シェル内側から嵌める
- ギミック: WS2812 LED (目バックライト/赤ランプ)、DFPlayer サウンド。頭部は
  完全固定 (可動部なし, `docs/assembly.md` §3)。未実装の頭部ヨーに対応する
  CH_HEAD/ch12は、現在のfirmwareでは常時出力停止。
- **音声会話**: 砲身 (Mouth_Cannon) 内蔵のマイク (INMP441) + スピーカー
  (φ20mm, MAX98357A アンプ経由) で、Wi-Fi 越しのブリッジ
  (`tools/voice_bridge.py`) と STT→LLM→TTS (声クローン) の音声会話ができる
  (半二重運用。詳細は `docs/voice.md`)
- **カメラ (2026-07-28 頭部の中央目へ移設)**: **頭部の中央可動目を固定
  カメラ目に置換したもの** (`eye_pod_camera`, 瞳径φ10mm) に独立 WiFi
  カメラモジュール (推奨: Seeed XIAO ESP32S3 Sense) を内蔵。ポッドの
  メインアイ (Cabin_Eye) は元パーツのまま無加工。撤去理由: ポッド前面の
  位置は前方視界の約80%が自機体に遮蔽されることが実測で判明したため
  (`tools/check_camera.py` [4])。瞳をキャップ軸から偏心させ正しい取付
  位相でグルーすることで、ソケット法線の仰角 (~46.6°) を相殺し光軸を
  ほぼ水平前方 (残差 ~8.6°) へ向ける。本体制御 (ESP32-WROOM/PCA9685) とは
  無関係に自前で WiFi 接続し静止画/MJPEG を配信、`voice_bridge.py
  --camera-url` が発話のたびに1枚取得して LLM へ画像として渡す
  (「見て」答えられる。詳細は `docs/voice.md` §5)
