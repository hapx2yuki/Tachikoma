# 物理シミュレーション監査・I-08 (#78)

確認日: 2026-09-05。対象: `tools/sim_physics.py`、`tools/sim_gait.py`、`tools/export_urdf.py`、実際の `gait.h` / `ik.h` / `leg_output.h` と再生成後の URDF。現物への書き込み・意匠変更は行っていない。

**結論: 現行形状は指定した剛体・摩擦・サーボ近似条件で前進・旋回できる。ただし、現物の接地と耐荷重を証明できる状態ではない。** 特に RV06 の機構診断で、トゥおよび硬い足本体が TPU パッドより先に接地することが確認された。シミュレーションはそれらを単一凸包・同じ摩擦係数で扱うため、条件付き PASS を「TPUで支持できる」「細い装飾トゥが荷重に耐える」「実機で滑らない」の根拠に使えない。

## 修正した欠陥

## 物理実行結果

親担当による CAD→頭部加工→URDF 再生成後に実行。公称質量 **2.78985kg**、関節PDゲインは既存値を維持、初期状態は立位配置済み、自己衝突は無効。腕は READY + 前脚からの退避判定のみ。

合否基準は実行前に固定した: 転倒なし（|roll|/|pitch|≤30度、胴高が基準の半分以上）、非脚リンクの接地なし、IKフォールバックなし、数値警告なし、指令方向の平均速度≥5mm/s、指令方向の旋回≥1度、各脚軸のトルク飽和時間率≤5%。**これらはシミュレーション試験の数値基準で、実機の安全率や連続運転定格ではない。**

前進量は「歩行区間の最初/最後の1周期平均位置」の差なので、8秒歩行に対する比較時間は **6.4秒**。全8秒の総移動距離と混同しない。

## 残る制約・Issue の切り分け

1. **RV06（足の支持）を最優先で解く。** 機構担当の115mm静止姿勢診断では、後脚のトゥ最下点-5.813mm、TPUパッド最下点+8.699mm、同脚差14.512mm。トゥを外しても硬い足本体がTPUより先行する。形状の最小修正、部位ごとの摩擦・支持面の分離、細い装飾の耐荷重は本シムのI-08修正から切り離し、物理製作を直列の確認にする。
2. 実重量・重心（I-01）、片脚荷重/サーボ力（L-02）、歩行電流（L-10）、電源容量（EL-09）が未測定。質量1.3倍やトルク0.9倍は指定した仮定の感度試験であり、実測を代替しない。
3. 樹脂の撓み、印刷方向、ホーンのガタ、電池・UBECの電圧低下、連続保持による熱、腕の全動作、起動/再有効化の姿勢、自己衝突は未検証。全身・全動作が動くという合否へ拡張しない。
4. `export_urdf.py` の慣性は均質密度・推定質量による概算で、電装位置にも概算がある。静的安定や慣性行列の形式検査が通っても、現物の重心測定が済んだ意味にはならない。
5. 旧 `HANDOFF.md` の速度上限18.75mm/s（30/1.6）は接地率を落としている。接地区間は30mmを `DUTY×CYCLE_T=1.2秒` で掃引するため、無滑り・射影なしの理想的な接地掃引速度は **25mm/s**。現行公称実行の22.75mm/sはこの範囲内。

## 一次資料

MuJoCo の URDF 読込実装では `velocity` の読み込みが無効化され、`effort` は関節の力制限へ渡されることを確認した。[公式ソース xml_urdf.cc](https://github.com/google-deepmind/mujoco/blob/main/src/xml/xml_urdf.cc)（確認2026-09-05）。

アクチュエータ出力の `forcerange` と関節側の力制限は別に作用する。速度制限とは別である。[MuJoCo Modeling: Force limits](https://mujoco.readthedocs.io/en/stable/modeling.html#force-limits)（確認2026-09-05）。ダンピングと armature の定義も公式説明を参照した。[MuJoCo XML Reference](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-joint)（確認2026-09-05）。
