# 股ピッチ用サーボ穴の再貫通に対する独立評価

天板の合成でサーボ穴を埋め戻していた不具合に対し、全形状合成後に `servo_pocket` と `servo_tab_holes` を再減算する修正を確認した。元の外形を増やさず、サーボと共有していた空間を除く幾何修正として妥当。印刷強度の合格は主張しない。

候補STLは単一の閉体、18,729.996mm³。サーボ負形状との残交差0.000228mm³、ホーン負形状0.000007mm³、タブビス穴0.000016mm³。上板の基準下面はcase半幅+公差=10.3mmで、その上にある直接支持板の旧新差集合は0.000100mm³。ホーン腕溝の下には3.600mmの床があり、pilot x14.4/19.84mmの各穴の周囲4半径×16方位でも同じ厚さだった。

| 上向き力 F (N) | pitch反力偶力 (N·m) | 上板中実の安全率近似 | 壁1.6mm/40%の安全率近似 |
|---:|---:|---:|---:|
| 22.370 | 1.770 | 2.403 | 2.295 |
| 22.370 | 1.956 | 2.227 | 2.126 |
| 37.278 | 1.770 | 2.063 | 1.970 |
| 37.278 | 1.956 | 1.932 | 1.845 |
| 44.730 | 1.770 | 1.927 | 1.840 |
| 44.730 | 1.956 | 1.812 | 1.730 |

すべての荷重条件で旧新の上板値は数値誤差内で一致する。最低断面は走査開始側x=0.0137mmでZy=102.742mm³（中実）、98.101mm³（壁1.6mm/40%）。全断面には離れた下側枠も含まれて合成梁の断面係数が非常に大きくなるため、その値を単独で合格根拠にしない。

これは55MPaを仮の曲げ強度とした比較感度で、実スライサの経路、ねじ抜け、局所応力集中、積層異方性、サーボ反力の3次元分配は未確認。力Fと偶力Mを同時に置いた条件も、実シムから取り出した同時反力ではない。SFが2を下回る組合せがあり、実製作の強度・締結確認を省略できない。旧STLも同じ直接上板を持つため、この弱さが今回の切削で新たに発生したとは解釈しない。

再現用コマンド:

```bash
.venv/bin/python tools/inspect_coxa_pocket_candidate.py --before docs/audits/20260905-round2/coxa-before-pocket.stl --after docs/audits/20260905-round2/coxa-pocket-candidate.stl --json /tmp/coxa-pocket-review.json
```

- `coxa-before-pocket.stl`: 天板後端修正後、穴再貫通前の現行STLを保存。
- `coxa-pocket-peer-final.json`: 2形状×全断面/直接上板の全0.2mm走査、6荷重×2印刷近似、全レイ結果と入力hash。
- `coxa-pocket-peer-final.log`: 実行終了0は幾何に限る。`print_strength_status=UNVERIFIED`。
- `tools/tests/test_coxa_sweep.py`: r10の保持面から合法的なサーボ空間を除いても、COXA_REAR_MIN_X=-1の過剰切除を拒否する負例は合格（親担当のfinal回帰ログ）。
