# 第2次監査：物理シミュレーション・URDF

**現行形状の組立と実機歩行を合格とは判定できない。** 実C++の出力、全パーツの組立変換、固定サーボの占有を加えて調べると、停止保持で部品の実交差がある。床への力も、従来想定のTPUではなく硬いトゥに集中していた。これらを接触除外で隠さず、モデルの誤りは修正し、機構の欠陥と区別した。

最終統合では89条件の動的計算、18姿勢の実メッシュ交差、16回帰を実行し、入力一致を確認した。`stress-before-cad/`、`*-before-final.json`、`before-mouth-clearance/`、`before-stl-repair/` は途中の設計を調べた保存資料で、現在のハッシュ一致を主張しない。特にSIM-12修正前の動的結果は、未更新の派生慣性定数を含むため最終根拠へ流用しない。第1次の [物理監査](../20260905/simulation.md) と動画・10条件は上書きしない。

## 調査範囲と事前の判定基準

担当ソースは `sim_physics.py`、`sim_gait.py`、`export_urdf.py`、`check_urdf.py` と追加した接触・試験・回帰コード。現在のURDF一式、同梱画像、旧7/31フォルダ・8/22ZIPを含め、ファイル単位の読解・解析・実行方法は [coverage-simulation.json](coverage-simulation.json) にSHA-256とともに記録する。

[事前の試験定義](simulation/test-plan.json) は動的試験前に保存した。数値警告なし、roll/pitch各30°以内、股軸の床面からの高さが指令体高の50%以上、IK失敗0、脚以外の床接触0、各脚軸のトルク飽和率5%以下、指令方向へ平均5mm/秒以上、旋回指令方向へ1°以上を既定の比較基準とした。2msと1msの移動距離差5%以内を数値刻みの比較に使う。これらは実機の安全・性能規格ではない。

基本71条件には、前後左右、両方向旋回、複合、急反転、高さ110/115/120/125/130mmと遷移、16位相の停止再開、±5/±10°斜面、2/5/10mm段差、2/5/10N外力、質量・出力・速度・摩擦の感度、60/180秒連続歩行、5/5.5/6V、全リンク/部品/凸分解での自己接触を含む。未採用のTPU靴候補は別の4条件で比較する。

さらに斜面へ本体を予め揃える4条件、未同定の関節補正慣性・粘性・制御ゲインの8条件、その低慣性条件を細かい刻みで確かめる2条件を追加した。それぞれ専用フォルダの `plan.json` に実行前の条件・基準・実行コードのSHAを保存した。身体を斜面へ揃える外部配置を、自動姿勢適応と混同しない。

## 実C++と物理モデルの境界

脚目標とスルー後角度の回帰は1563フレーム、各方向・停止再開・高さ変更を含み、Pythonとの最大差は0.000895°だった。別の回帰で20軸の通電順、2秒の起動完了、4.88µsのPWM刻みを確認した。通常起動の初期脱力を、保持姿勢に既に立たせた計算で置き換えない。

MuJoCoは500Hz、C++からの指令は50Hz。各軸の実トルク・最大速度・追従誤差・飽和率、正の機械仕事率の平均/最大/95百分位、10Hzの軸トルクと速度を保存する。軸の無負荷速度を超えて外力で逆駆動されることはあり得るため、速度自体を強制的に切り詰めない。

SIM-11は公式仕様の「剛体内の衝突探索木が慣性座標に沿う」という説明と整合する。候補の質量特性をコンパイル前に確定させ、接触の幾何と探索境界を一緒に構築する。[MuJoCo衝突検出](https://mujoco.readthedocs.io/en/stable/computation/index.html#collision-detection)

SIM-12は [修正前](simulation/derived-mass-constant-reproduction.json) で、質量を1.3倍へ変えた本体の実合計が3.57180kgなのに `body_subtreemass` は2.74754kgのまま、既定でも最初の脚軸の `dof_invweight0` が840.174のまま残り、再計算で442.538へ変わることを再現した。[修正後](simulation/derived-mass-constant-after.json) は関連する全配列について `mj_setConst` 再計算との差が0。コンパイル後のモデル変更を全行見直し、運転中に変える値は速度・通電に応じたアクチュエータの力上限だけにした。

位置制御ゲイン、各関節の粘性0.02、回転慣性補正0.001は未同定の値である。自由ベースへ架空の粘性・慣性は加えていない。印刷質量は体積と表面積の近似、重心・慣性は均質メッシュの仮定。実サーボの連続トルク、電源電圧降下、ホーンや樹脂の変形、バックラッシュ、摩擦、ゴム圧縮・接着強度は未測定で、今回の剛体計算はこれを証明しない。

## 自己衝突：偽接触と実干渉

18姿勢（C++の停止保持指令、機械的0度、歩容16位相）で全候補を出す。主な最終資料は [20ケースの実交差診断](simulation/all-pairs-native-20servos-final.json)。PWM量子化後の指令角に合わせた幾何診断であり、実サーボの角度を測ったものではない。以下の旧交差量は記録時の入力に対するもので、最終形状は末尾の統合試験を参照する。

- 元のリンク凸包では初期の最大侵入が非隣接8.886mm、隣接も含めると24.627mm。単一部品凸包でも19.029mm、VHACDでも10.011mm。凸分解だけで全て消える偽接触ではなかった。
- 実STL同士で、脚付け根の天板前後40.678mm³、シャーシ対thigh_cap/大腿外装、腕の肩対上腕、上腕対前腕、肘殻対前腕などが交差した。修正後の同じ18姿勢では、前後coxa、旧上腕対前腕、旧肘殻対前腕の交差は消失した。残る干渉は末尾に記す。
- 腕はURDF変換を使わない [独立再現](simulation/arm-independent-intersections.json) も行った。旧上腕対前腕は肘0°で598.565mm³、40°で396.104mm³、95°でも36.774mm³。名前や鏡映の誤りではなく、元STLの実交差として機構担当へ渡した。
- 前脚yaw主ケースと目の可動ポッドは約3848/3865mm³、腕肩pitchケースと前脚pitchケースは実C++保持で約413/451mm³交差した。
- 同一baseの内部でも、前脚yawケース対固定目サーボ本体は2033/2457mm³、目保持板は1792/1578mm³交差した。固定ケース対HeadTopも4脚572〜1316mm³、腕100〜106mm³。1つの剛体内部の形状矛盾は、MuJoCoの自己衝突設定では表れない。

旧結果の `Head_Plate` と `Head_Bottom_Cap` は組立で不採用と判明したため、その2部品に対する交差を現仕様の欠陥として数えない。接着面の接触と体積重なりも区別する。印刷した閉じた部品が体積を共有する場合、単に「嵌合予定」として省略せず、必要な逃げ加工・基準面を機構側で確かめる。

VHACDは近似であり、分割数・元体積・凸片体積・入力ハッシュを [キャッシュ台帳](simulation/collision-cache/) に残す。極薄片がMuJoCoで平面と判定される場合は削除せず、元片を全包含する最小厚0.02mmの箱へ置換し、最大追加半厚0.01mm以下を記録する。これも接触形状の近似誤差として扱う。[MuJoCoの接触計算](https://mujoco.readthedocs.io/en/stable/computation/index.html#contact)

## 床支持と電力

形状修正前の材料分離試験では、歩行区間の反力積分約173.7N·sが硬いPLAに載り、TPU反力は0だった。部品単位の凸包でもVHACDでも同じ傾向で、摩擦1を全材質へ与えた場合だけの歩行成功をTPU支持の証明に使えない。さらにトゥ行列100%と印刷150%の不一致が見つかったため、旧トゥでの数値は現仕様の接地量を過小評価している。

TPU靴＋トゥ根元の隠し逃げは機構担当の未採用候補。初回の候補試験はSIM-11の生成器不具合で3 FAIL/1 FALLとなったが、これは無効な物理モデルの結果である。修正前資料は `foot-candidate-before-bvh-fix/` に保存し、判定を採用しない。各脚へ組立行列で移し、追加質量と慣性を反映して4条件を比較する。摩擦・ゴム圧縮・保持強度の実測は別に必要で、外観変更を既定のCADへ自動採用しない。

DS3218の6V内挿最大トルクは約1.956N·m、無負荷速度7.034rad/s。MG90Sは約0.203N·m、13.090rad/s。メーカー資料の端点からの直線内挿であり、実個体の値ではない。MG90Sページは電圧表記に不整合がある。[DS3218資料](https://www.dsservo.com/down.asp?id=22)、[TowerPro MG90S](https://towerpro.com.tw/product/mg90s-3/)

正の機械仕事率は電源入力の理想的な下限の手掛かりで、静止保持時の銅損・駆動回路・電源損失を含まない。6V/10Aの適合は、軸トルクだけから確定せず、親担当の電力感度計算と実電流・温度測定へ引き継ぐ。
