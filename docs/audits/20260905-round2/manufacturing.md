# 印刷済み品・既存3MFへの影響

2026-09-05。元モデル58個、既存3MF27個、従来の画像・動画39個は開始時とSHA-256が一致し、保存されている。
全STL再生成で印刷用12ファイルが変わった。**10ファイルは形状変更、肘カバー2ファイルは形状を保つ配置変更**。
全数を再印刷する指示ではない。現物の版・寸法・材質をP-02/P-05で照合し、再使用・内部加工・再印刷を判断する。
頭部収納などに未解決項目があるため、今回の生成物を完成版の一式として追加印刷しない。

## 本流へ反映した形状

| 部品 | 変更 | 既印刷品の扱い |
|---|---|---|
| `coxa_bracket` / `_m` | 天板後端を局所X=-21から-12mmへ短縮。正形状合成で埋まったpitchケース/タブ/配線ポケットを再切削。ケース枠・軸・ホーン溝床3.6mmを保持 | 標準2/鏡像2。旧版から1個あたり約5717mm³除去。後端だけ切れば済むと考えず、新旧断面と工具経路を確認 |
| `shoulder_bracket` / `_L` | 上腕円板が通る内側の張り出しを除去 | ねじ座を保つ内部加工の候補。現物の工具経路・層割れを確認 |
| `forearm` / `_L` | 上腕箱枠の逆掃引と、配置を直した肘殻の球包絡を逃がす。軸間16mm・ホーン・手首端面を保持 | 開始時より約1785mm³小さい。荷重経路が細いため、新旧STLの比較と実物強度を経て加工か再印刷を判断 |
| `Mouth_Cannon_Bored` | マイク受けの挿入ボアとキー溝を連結 | 内径加工が必要。完成したマイクを無理に押し込まない |
| `Mouth_Neck_Bored` | Ball球面座とCapの隠れた受け座を追加 | 開始時より約2179mm³除去。残肉・接着・工具経路を現物確認 |
| `chassis` | MouthBall/Neck/Capの内部逃げ。前90度タブにφ10×3mmカラーを加え、5mm厚の支持リングを保持 | 単純切削だけではカラーが追加できない。旧品の別体補強か再印刷を頭支持RV-13と合わせて設計。ねじ長も3mm増厚に対応が必要 |
| `Head_Bottom_Armcut` | 肩変更を反映。旧版で不要に除いた約2294mm³を復元 | 主に材料の復元。旧品の残肉・支持方法を確認し、廃棄を自動判断しない |

腕の実STLは1664姿勢と固定4項目で交差0。口とシャーシは下方30mmの挿入363姿勢と支持材の検査を通した。
coxaは6ペア1,989,384角度組合せと格子間回転の上界を評価し、連続範囲の保守的隙間下界0.963mm。
これらは印刷公差・接着・疲労を測定した結果ではない。固定爪とMouthの小さいキー嵌合は別に未確認の交差が残る。

シャーシの保存後に生じた退化面は0.001mmの簡約で修正し、形状体積差0.004mm³未満。
共通STL変換も内側空洞を反転しないよう修正し、保存後の閉体・向き・有限体積・元CAD体積との一致を必須にした。

差分: [12ファイルの寸法・体積・ハッシュ](manufacturing-diff.json)。保存確認: [124ファイルの照合](manufacturing-preservation.json)。
最終検査: `final-geometry/generate/`、`final-geometry/verify/`。

## 形状を変えず配置を訂正したもの

- `elbow_shell` / `_L`: 原球中心を肘軸から局所Y=-13.8mmへ。形状は双方向の頂点距離0.00002mm以内で一致。既印刷カバーを追加拡大・再印刷する必要はなく、取付位置を変える。接着保持は未実測。
- toe12個: 組立行列100%を印刷指定150%へ訂正。根元点は維持。既存150%印刷品をさらに拡大する意味ではない。
- Cabin Back: 6.3075mm下げ、既存Peg2本の穴をFrontへ合わせた。Back装飾6個も追従。
- HeadTop/Bottom: 現行configのY=11mmへ表示・検査を統一。HeadTop高さ57.7mmもconfig参照に一本化。
- Head_Plate/Head_Bottom_Cap: 既存組立で不採用だった2部品を表示・URDFから除外。元ファイルは保存。

## 既存3MFの不一致

全27個のうち9個に現行STLとの形状不一致がある。これは旧ファイルが破損したという意味ではない。

| 3MF | 不一致の部品 |
|---|---|
| `TACHIKOMA_Phase0_PETG.3mf` | 旧tibia/femur。現行脚骨格として扱わない |
| `PETG_1_Chassis.3mf` / `PETG_Walk_1_Chassis.3mf` | シャーシ |
| `PETG_4_CoxaArm.3mf` | coxa・肩・前腕 |
| `PETG_Walk_2_CoxaFemur.3mf` | coxa |
| `PETG_Walk_4_Rest.3mf` | 前腕 |
| `PLA_Matte_Blue_2.3mf` | Head_Bottom |
| `PLA_Matte_Gray.3mf` | Mouth_Cannon |
| `claw_mount_L.3mf` | 肩・前腕。腕7部品の壁2/15%設定も現行指定の壁4/40%と異なる |

`elbow_shells_PLA_Matte.3mf`は配置を除いた印刷形状が一致し、再利用候補。
現存の`PLA_Matte_Blue_2.3mf`にはMouth_Neckが入っていない（生成定義には含まれる）。今回のNeck修正を、既存3MFの不一致一覧だけで見落とさない。印刷済みか、別の旧版から印刷したかは現物履歴を確認する。
元3MFには印刷済み品を除いた手動編集があるので、一括上書きせず、必要な部品・個数を別出力先で確認する。
距離`inf`は事前の体積/形状不一致で位置合わせを打ち切った記号で、無限の寸法差を意味しない。
結果: `final-geometry/verify/check_print_artifacts.json`。

## 材料量の概算

本流STLと不使用品除外を反映した概算は、PLA青833g、灰130g、黒40g、白30g、赤4g、PETG538g、TPU2g。
壁と充填率による概算で、スライサ実消費、サポート、失敗分、未採用候補は含まない。
完成版の購入必要量として確定しない。`final-geometry/filament-estimate.log`を参照。
