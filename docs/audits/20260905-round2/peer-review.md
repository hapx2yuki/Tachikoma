# coxa・3MF抽出の独立レビュー

2026-09-05、`tools/check_coxa_sweep.py`、`hardware/src/make_leg.py` の後端切削、`tools/extract_meshes.py` を読み、実体比較と負例で確認した。本流のソース・STLはこのレビューから変更していない。検査の不足2点は主担当へ報告し、主担当が修正した後の回帰試験を実行した。

- **coxaの現形状は合格**。幅方向を含むXY凸包は3D実体の保守的包絡となる。刻みを0.137°へ変更した独立計算でも、格子間を含む最小距離下界は0.93217 mm。式 `4R sin(step/4)` は2物体が最大半刻みずつ回転する変位の和で正しい。個別制約を1刻み、合計制約を2刻み広げるmaskは、実際の到達角の最近傍格子を除外しない。後脚のpod側制限を緩めた検査も保守的である。
- **箱枠保持とホーン座保持は別**。実際の後端X=-12 mmではr10内の旧材料喪失0、ミラーの実体対称差0を独立確認した。一方、X=-1 mmへ変更するメモリ内の負例では、箱枠喪失0なのにホーン座683.995 mm³が失われる。元のcheckerは箱枠だけを確認し、コメントのホーン周囲保持は判定していなかった。主担当がr10ホーン座の差分判定とミラーの実体対称差判定を追加した。
- **3MFの単位・同名原型保護は機能**。XML属性順、単位変換、既存ファイル保存、異なる同名原型の全体拒否を確認。追加で `Part_1.stl_14.model` を `Part` へ縮めてしまう名前処理を指摘し、主担当が意味を持つ `_1` を保持するよう修正した。

`tools/tests/test_coxa_sweep.py` はソース/ファイルを書かずにパラメータだけを変え、箱枠を維持してホーン座を失う負例を必ず不合格にする。修正後のcoxa1件＋抽出4件、計5件が合格。ログは `coxa-extract-peer-tests.log`。独立格子と形状比較は `coxa-peer-review.json`。

この確認はブラケット同士のヨー可動域と抽出処理を対象とする。サーボ現物寸法、ねじ保持、ケーブル、疲労強度、他の意匠部品との全組立を認定するものではない。
