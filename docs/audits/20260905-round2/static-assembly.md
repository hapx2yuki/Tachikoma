# 固定部品の全組合せ検査

2026-09-05。`check_static_assembly.py`は、同じbase_linkに固定される58部品の1653組を列挙し、外包が重なる96組を実メッシュで計算した。計算エラー0、0.01mm³を超える体積共有51組。動力学で同じ剛体の内部を自己接触させても発見できない欠陥を対象にしている。

この51組は**口のシャーシ/Cap逃げを追加する前**の記録である。修正後の全組合せは最終統合ログを参照する。接着や締まり嵌めを想定できる部品も、根拠なしに正常とせず、[個別分類](static-intersection-triage.json)に残した。

| 主な組合せ | 交差 mm³ | 判断 |
|---|---:|---|
| シャーシ–MouthBall / Neck | 1149.468 / 115.507 | 原型座標・現配置の一致を独立確認。内部逃げが欠落 |
| MouthCap–Neck | 112.880 | 首先端へCapが入る。覆われる内部座を修正 |
| CabinFront–Eye | 7784.869 | リングにbbox中心を置いた古い近似。半厚7.39mmを加えても交差3296.55。電装空洞候補でも3106.10 |
| pod_neck–TailJointBlue / Ball | 3281.741 / 2047.605 | 先端の丸軸だけでは中実部分へ梁全体を通せない |
| TailJointBlue–Ball | 3016.283 | 2部品自身も共有体積があり、相対位置/嵌合が未成立 |
| 前yawケース–目ケース | 2033.397 / 2456.554 | 同一剛体内部の購入部品の衝突。頭内の再配置が必要 |
| HeadTop–Insert1 / Insert2 | 128.245 / 32.822 | 原型でも156.385 / 99.971。新しい頭加工が作った問題ではない |
| HeadTop–推定Screw2 | 8.723 | 原型でも再現。既存の推定配置を要修正 |

目の位置は0〜15mmの0.5mm刻みで比較した。Frontだけなら13mmで非交差になるが、neck/Blue/Ballも含む全非交差案は0件。外へ押し出すだけで完了とはしない。[目位置比較](cabin-electronics/eye-position-probe.json)

HeadTopの装飾は元形状との[比較](head-decor-original-comparison.json)でも重なりを再現した。Dome/Plug/実測Screw1は交差0（Screw1は約0.000038mm³の数値誤差）。推定Screw2とInsertの問題を、全ての装飾の誤りへ一般化しない。

別リンク間の干渉は[物理監査](simulation.md)の18姿勢を使う。肩ピッチケースの向きだけを30度刻み12候補で変えた比較でも、全18姿勢を通す案は無かった。前脚ピッチケースとの最悪交差は最良の90度でも298.60mm³で、さらに肩の旧箱枠768.08mm³・腕ガード35.90mm³へ入る。軸位置を保った単純なサーボ反転を修正として採用しない。[比較](arm-pitch-case-rotation-candidates.json)

独立した電装室・カメラ・足靴の候補の部分合格は、この全体組立の不成立を解消した意味ではない。配置に依存する支持柱、脚カバー、首・CabinをRV-13/14/15へ分け、共通取付軸の確定を先行させる。

## 最終形状による全リンク内検査

`final-geometry/verify/static-all-pairs.json`では152部品、各リンク内の全1898組を列挙し、191組を実体計算した。計算エラー0、0.01mm³を超える体積共有99組。
coxaのケースポケット、肘殻/前腕、口とシャーシの修正を反映した結果である。旧base限定51組と、異なる母集団の数を単純比較しない。

| 追跡先 | 組数 | 未解決の対象 |
|---|---:|---|
| RV-15 | 29 | Cabin/首/装飾の全長接合・座面 |
| RV-09 | 13 | 頭の実ケース収納、殻/梁 |
| RV-16 | 16 | 大腿/脛ガードと殻・骨格 |
| S-08 | 3 | 頭装飾の既存配置 |
| RV-06 | 16 | トゥ/硬い足/TPUの接合と支持 |
| RV-17 | 20 | 左右の固定手内部 |
| RV-08 | 2 | Mouth_Keyの小さい嵌合交差 |

[99組全件の分類](static-intersection-final-triage.json)には部品名・体積・追跡先を残した。
これは99個の独立した欠陥という意味ではなく、左右反復や圧入/柔軟材の公差が未確認の接合も含む。
大きい機構交差と小さな接合公差を区別し、全件を「接着で吸収できる」と免除しない。
