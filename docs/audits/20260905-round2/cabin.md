# Cabin 電装室・背面蓋の再設計候補（2026-09-05）

現行の殻は内部まで中実であり、そのままでは基板を収容できない。前殻に後方からアクセスする左右2段の収納室を設け、各棚を M3×10 タッピング2本で固定する候補を作成した。背面蓋は既存ペグ穴を使う交換ペグの板ばねで保持し、後方へ引いて取り外す。外側の新穴と磁石は不要。**収納室・棚・ラッチの69項目は合格だが、Cabin Eye、首、Ballなどとの全組立には実体交差が残る。全体の組立合格ではない。現物寸法・熱・保持力の確認も残り、候補は標準生成・印刷対象へ自動適用していない。**

## 確定した既存欠陥と修正

- `Cabin_Front_Blue.stl` は 1,956,201 mm³、`Cabin_Back_Blue_Repaired.stl` は 679,935 mm³の中実。基板を収める空洞・固定座・配線経路が設計されていなかった。
- 後殻の従来高さ Z=55 mm では2本の元ペグ穴が前殻に対して6.3075 mmずれていた。後殻Z=48.692503 mmに合わせると、元ペグ2本の殻との交差は0になる。前の配置では同じ2本が計3,727.19 mm³交差した。`config.CABIN_POSES`、`config.CABIN_PEG_POSES`、`kit_assembly`、装飾6個への位置反映は主担当が統合済み。
- Boolean内部で閉じた形状でも、書き出したSTLを読み戻すと元殻の極小稜線が重なり4面接続になる現象を捕捉。候補の最終書き出しは0.015 mm以内の簡略化を行い、**再読後の閉体・単一体**を改めて確認する。外観寸法の基準0.1 mmより小さい修復であり、既存STLは上書きしない。

## 候補の構成

全成果物は `cabin-electronics/`。全て**シャーシ底面Z=0の組立座標**で、さらに姿勢補正を重ねない。寸法の定義は `tools/design_cabin_electronics.py`、ラッチは `tools/design_cabin_latch_candidate.py` に集約した候補値である。製造対象に採用する際は `hardware/src/config.py` へ移す。

| 部品 | 候補STL | 数量 | 役割 |
|---|---|---:|---|
| 前殻 | `candidate_cabin_front_with_wire_route.stl` | 1 | 収納室、棚固定座、φ8配線路 |
| 後殻 | `candidate_cabin_back_with_latches.stl` | 1 | 左右渡り配線室、ラッチ受け |
| 左右棚 | `candidate_carrier_0.stl` / `candidate_carrier_1.stl` | 各1 | 基板の絶縁保持・ベルト穴・USB開口 |
| 交換ペグ | `candidate_latch_peg_lower.stl` / `candidate_latch_peg_upper.stl` | 各1 | 前殻側は元形状、後殻側に各2本の板ばね |
| 比較用 | `candidate_cabin_front_pockets.stl`、`candidate_cabin_back_crossover.stl`、`candidate_peg_*.stl` | — | 配線口やラッチを追加する前の比較形状 |
| 検査用 | `candidate_latch_peg_*_deflected.stl`、`candidate_wire_route.stl` | — | 変形・通線包絡。印刷部品ではない |

左右棚中心X=±32 mm。下段収納室は幅36×奥行71×高さ38 mm、上段は幅35×奥行59×高さ31 mmで、背面開口付近を追加で逃がす。棚板厚2.4 mm、壁厚1.5 mm。2本ずつの後方から入れるM3×10は、棚3 mm＋棚と座の間1 mmを越え、固定座へ6 mmねじ込む。下穴は共通定数 `C.M3_TAP`、通し穴は `C.M3_FREE` を使用。皿頭のねじでは面圧が変わるため、実購入ねじの頭部と下穴適合は試験する。

基板は裸の銅面を棚へ接触させず、既存の絶縁材・ベルトで固定する。棚の穴は幅2.6×長さ6 mmで、3 mm超の結束バンドは入らない。ベルト・フォームの厚みは下の予約体積内に含めること。接着だけでの基板固定を前提にしない。

|---|---:|---|
| ESP32本体＋縦ヘッダ | 30×58×28 | PCB 58×28を収める予約。実端子・USB位置は未確認 |
| UBEC | 30×59×28 | HOBBYWING 45×20×16.2 mm本体を含む。購入記録のHENGE 8Aの適合は未確認 |
| DFPlayer | 26×26×20 | 実ピン・microSD・プラグ要実測 |
| MAX98357A | 24×22×20 | 基板と端子の予約。実モジュール種類要実測 |
| 5V変換基板 | 28×38×20 | mini560の種類、調整部・放熱要実測 |
| USBプラグ | 14×29×12 | 後殻を外すと挿入空間を確保。後殻を閉じたままでは交差する |

HOBBYWINGの寸法は[メーカー掲載のUBEC-10A-V2](https://www.hobbywing.com/products/ubec-10a-car79)を参照。購入履歴のHENGE 8Aと型番が異なるため、これだけで所有品の適合は認定しない。XIAOは短いカメラFPCの制約から頭側へ配置する方針であり、Cabin内の予約体に含めない。

## 通線と保守

左右の配線は後殻内側の幅74×奥行12×高さ12 mmの渡り空間を通り、前殻のφ8経路へ合流する。経路は曲げ半径25 mmで、ネック接合面のX=0、Z=10 mmへ出る。元ペグ周囲を避け、棚と全基板予約体に交差しない。前殻のφ8出口は既存ネックに隠れる接合面であり、外側の見える面への穴は追加していない。

ネック側のφ8孔と出口候補は `neck-wire-candidates/` に別途作成されており、根元補強と併せて主担当・機構担当が確認する。旧ネック40%印刷近似の安全率2.72は要求3未達だったため、**通線孔だけを旧ネックへ追加して製造してはいけない**。線束径、コネクタの通過、屈曲半径、蓋を抜くための余長、熱上昇は未確認。USB接続時は後殻を取り外し、電源の接続順は改訂した配線手順に従う。

## 背面蓋の保持

交換ペグ2本は前半形状を元ペグと一致させ、**Front側にだけ接着**する。Back側と板ばねには接着剤を付けない。各ペグ後半の板ばね2本が0.6 mm噛み合う。挿入側30°、抜去側60°の斜面で、蓋をまっすぐ引くと板ばねが押し下がって外れる。外側の解除穴や別部品は不要。蓋の装飾を引っ張らず、殻本体を持って操作する。

- 有効梁長15 mm、幅7 mm、厚さ1.6 mm。無荷重で嵌合し、閉じたまま変形を保持しない構成。
- 蓋を0.25 mmずつ動かす実メッシュ検査では、必要な自由端変形は下ペグ最大0.651 mm、上ペグ最大0.697 mm。0.85 mm押下形状に対して蓋を20 mm連続移動する全包絡の交差は0。
- 片持ち梁の式 `ε=3tδ/(2L²)` では最大ひずみ約0.744%。これは切り欠きの応力集中や積層方向を含まない。
- 印刷PETGの弾性係数を **800～2000 MPaの仮定範囲**で振ると、4本が同時に効く理想状態で挿入力2.74～6.84 N、抜去力8.21～20.52 N。摩擦・寸法誤差・実材料係数は含まず、実測した保持力ではない。

試験はペグ単品と対応するソケットを先に印刷する。層が梁根元で剥がれる向きを避け、梁長方向へ連続する造形線と十分な外周を選ぶ。最終向きはサポート痕を含めて試験片で決める。目安として、無荷重で蓋が閉じ、開閉50回後にも白化・割れ・塑性変形がなく、実測した蓋重量と歩行時加速度から必要保持力を決定する。仮の確認条件は静的5 Nで外れず、20 N程度以下で手で解除できること。後者は快適な操作の仮目標であり、歩行保持の合否は実質量・加速度から決める。機体落下や転倒をこのラッチだけで防ぐ設計ではない。

## 再現と判定

```sh
.venv/bin/python tools/design_cabin_electronics.py
.venv/bin/python tools/design_cabin_latch_candidate.py
.venv/bin/python tools/check_cabin_candidate.py
.venv/bin/python tools/render_cabin_candidate.py
```

`candidate-report.json` は収納室と通線、`latch-report.json` は変形経路と梁の感度計算、`independent-check.json` は書き出したSTLを読み直した69項目の検査（全項目合格）と最終ハッシュを持つ。`candidate-parts.json` に6部品の体積・座標変換・候補パラメータ・製造前の未確認条件をまとめた。図は `candidate-overview.png`、組立閲覧用は `candidate-assembly.glb`。元キット姿勢の根拠は `tools/data/cabin_peg_alignment_candidate.json`。

| 項目 | CAD検査 | 実物の判断 |
|---|---|---|
| 殻・棚・交換ペグの閉体、単一体 | 最終STL再読で確認 | 印刷結果は未確認 |
| 元殻外形 | 0.015 mm簡略化、0.03 mm各軸膨張内を独立検査 | 元STLは未変更 |
| 外壁 | 接合面以外は3.3 mmの膨張で事前検査。簡略化を考慮して3.2 mm以上 | 実壁・印刷欠陥は未確認 |
| 棚・基板の挿入 | 後方70 mmの連続包絡で交差0 | コネクタと配線を付けた状態は未確認 |
| 閉じた蓋・交換ペグ | 殻・棚との交差0 | 接着と保持力は未確認 |
| ラッチの抜去 | 最大押下形状で20 mm連続経路が交差0 | 力・疲労・摩耗は未確認 |
| 基板予約体 | 殻・棚・配線との交差0 | 購入品の寸法が予約内か未確認 |
| ネック通線 | φ8・R25の候補経路 | 補強、線束、実負荷確認待ち |

## XIAO公式STEPの追加計測

機構担当が取得した2023年のSeeed公式STEPをOCCTで読み、組立の変換を適用して全部品の境界を計測した。単純な21×17.8 mmの箱はUSBの張り出しと拡張基板を含まず、カメラを取り外した予約寸法は **microSDなし22.782×17.780×8.030 mm、あり24.363×17.780×8.500 mm**。FPCコネクタ中心・寸法・右手系の平置き変換を `primary-sources/xiao-step-measured/camera-removed-summary.json` に保存した。

再現用は `tools/measure_xiao_step.py`。OCP/VTKは `/tmp/tachikoma-step-runtime` へ隔離して導入し、既存`.venv`を変更していない。`PYTHONPATH=/tmp/tachikoma-step-runtime .venv/bin/python tools/measure_xiao_step.py` で再計測できる。細部のSTEPには開いた面が含まれるため、部品STLは閲覧用であり、干渉検査は閉体の予約箱を使う。旧カメラ世代のモデルで、交換OV3660のFPC長・実購入基板の種類を認定するものではない。

## 追加の全組立確認：不合格

収納室を作った前殻を既存の意匠部品と比較する追加検査を行った。これは上記69項目に含まれていなかった関係であり、局所検査の合格を全組立の合格として扱わない。`cabin-electronics/external-interface-check.json` に元の前殻と候補の比較を保存した。

| 前殻との相手部品 | 元の交差 [mm³] | 候補で残る交差 [mm³] | 判定 |
|---|---:|---:|---|
| 既存pod_neck | 1199.55 | 1034.57 | 未解消 |
| Cabin_Eye_White | 7784.87 | 7548.03 | 未解消 |
| TailJoint Blue | 0.404 | 0.404 | 接触・配置要精査 |
| TailJoint Ball | 1152.80 | 829.91 | 未解消 |

収納室の空洞化ではCabin Eyeの食い込みを解消できない。元のrear JSON自身が「Eyeの境界箱中心を取付リング面へ置いたため、接着縁が約7.4 mm内側へ入る」と記録しており、取付基準面を合わせる修正が必要である。法線方向の0～15 mmの位置候補は `tools/probe_cabin_eye_alignment.py` で別途切り分け、標準位置は変更しない。元画像と接着縁の正確な基準が不足するため、非交差だけで正しい接合と判断しない。

首本体とBlue/ Ballの交差も意図した嵌合ではない。Blueの頭側先端とBallの円板は中実なのに、旧neck梁は全長にわたって貫通する。頭の局所逃げと強度だけを改善した候補は `neck-reinforcement-candidates/comparison.json` にあるが、全候補で全組立を不合格と明記した。Cabin内部、首の支持経路、意匠部品の基準面を一体として再設計する必要がある。

### Eye位置の有限比較結果

法線方向0～15 mmを0.5 mm刻み、さらに7.39 mmを測定した。Eyeの実メッシュの法線方向半厚みは7.3935 mmで記録と一致するが、7.39 mm押し出しても元Frontとの交差3296.55 mm³、収納室候補との交差3106.10 mm³が残る。neckとの交差は878.34から2054.83 mm³へ増加する。Frontとの交差が消える最初の格子点は13.0 mmだが、**首・Blue・Ballを含む全非交差姿勢は試した範囲にない**。半厚みを足すだけでは修正できないことを反証した。

`eye-position-probe.json` は全32姿勢、`candidate_cabin_eye_half_depth7p39.stl` は比較用の可視位置候補であり、正しい装着位置を確定したものではない。
