## 物理シミュレーション

最終形状で**89条件の動的計算**と、実C++から得た**18姿勢の全部品干渉**を実施した。
基本71条件は58合格・2不合格・3転倒・8初期接触モデル不成立。TPU靴候補4条件は条件付き合格。
追加14条件では斜面への初期配置、慣性補正/粘性/制御ゲイン、積分刻みを比較した。

実C++の20軸出力を1563フレーム照合し、最大差0.000895度。6V名目・推定質量2.726350kgの平地条件で歩容が動く。
180秒条件は約3.947m進むが、向きが約22.82度ずれる。現行部品の材料別計算ではTPU足裏に支持荷重が乗らない。
サーボケースを含む全体には初期干渉があるため、実機成立を示す有効な歩行合格に数えない。
+10度坂では事前に姿勢を合わせても材料別条件で後退し、低い慣性補正では粗い積分刻みの定量値に依存がある。

[全条件・仮定・不合格の詳細](simulation.md) / [実積分後の姿勢から作った動画](simulation/native-nominal-replay.mp4)。
この動画は平地の条件付き例。旧運動学デモや、不正STL/修正前の派生慣性定数を使った途中結果は最終根拠にしていない。

## Issue駆動の継続手順

既存の手動進捗をリセットせず、新規/未設定項目だけを初期化した。課題の完了待ちグラフに循環はない。

監査コミット公開後、11課題に固定リンクと実施済み/未解決の範囲を追記した。修正・検査を完了したRV-01/02/03/04/12（#81/#82/#83/#84/#93）だけを根拠付きでCloseし、ProjectをDoneへ更新。I-08は購入個体との照合が残り、E9/RV-05と機構・実機の課題もOPENを維持する。公開後の状態は [照合記録](publication.json) を参照。

- 先行: P-01/P-03/P-07で購入サーボ/電源/カメラの実型番・寸法を確定。設計型番と互換とは仮定しない。
- 直列: RV-09の軸/収納 → RV-13の頭固定・RV-14の脚カバー → 全生成 → 全体検証。
- 並行: RV-15/H-06の首・電装室、RV-16ガード、RV-17固定手、RV-11電源。共通ファイルと接合面は担当を決める。

部品を活かすためにも、実型番の確認前に頭内寸法を確定したり、未成立の受け座へ大量印刷を進めたりしない。
