## カメラユニット (2026-07-28 設計変更: 頭部中央目へ移設, `docs/voice.md` 参照)

**2026-07-28 設計変更**: カメラはポッド (Cabin) のメインアイではなく
**頭部の中央可動目を固定カメラ目に置換したもの** (`eye_pod_camera` +
`camera_carrier`, `hardware/src/make_camera.py`) に内蔵する — 左右 2 目は
キョロキョロ (BOM #2b) を維持。撤去理由: ポッド前面のメインアイ位置は
前方視界の約 80% が自機体 (シャーシ下面/クレードル) に遮蔽されることが
実メッシュ検証 (`robot_meshes(dress=True)` 全アセンブリのレイキャスト) で
判明したため。メイン ESP32-WROOM (脚/腕/頭部制御) は帯域・処理負荷的に
動画を扱わないため、**カメラは完全に独立したモジュールが自前で WiFi
(iPhone インターネット共有) へ接続し MJPEG/静止画 HTTP を配信する**
(本体の PCA9685/I2C バスとは無関係。`tools/voice_bridge.py --camera-url`
が発話のたびに静止画を1枚取得し Anthropic API へ画像として渡す)。
ポッドのメインアイ (`Cabin_Eye_White`) は元パーツのまま無加工で使う。
