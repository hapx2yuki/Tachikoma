## 1. 構造 (2 軸 + 依存)

- **マイルストーン = いつ (Go/No-Go ゲート)**
  `M0 準備完了` → `M1 片脚 Go/No-Go` (1.2kg リフト) → `M2 頭無し歩行` → `M3 サブアセンブリ` → `M4 フルドレス` → `M5 統合・完成`
- **エピック = 何の流れ (作業ストリーム, サブイシューで束ねる)**
  `E1 準備` / `E2 印刷キュー` / `E3 電装・ファーム` / `E4 脚・歩行` / `E5 腕` / `E6 頭部 (目・カメラ・音声)` / `E7 意匠シェル・Cabin` / `E8 統合`
- **依存 = 順番** — GitHub の blocked by / blocking。`is:open -is:blocked` で「今できること」が出る
- **占有リソース** — `res/プリンタ` (X2D 1 台 = 印刷は 1 本のキュー) / `res/本体` (シャーシ組立品)。それ以外は `並行作業OK`

## 3. 人数別のおすすめ配分

| 人 | 最初に取るもの | 理由 |
|---|---|---|
| オーナー | P-03 サーボ実測 → P-04 config 確定 → P-05 判断、要判断 (H-06 ESP32 位置) | クリティカルパスの入口。CAD/検証は Python 環境が要る |
| はんだができる人 | EL-01 電源 → EL-02 PCA → EL-04 中立化 → EL-05/06 ハーネス | 印刷・組立と完全に独立。M0 の半分 |
| プリンタ担当 | PR-01 → PR-02 → PR-03 (今すぐ) → P-04 後に PR-04 → … | 1 台なので 1 人が順に流すのが最も速い |
| 模型が得意な人 | P-02 印刷済棚卸し → (小物印刷後) S-05 Cabin 組立 → H-05 Mouth 一式 → 脚装飾 | 本体を待たずに進む純粋な組立 |
| ファーム/ソフト担当 | EL-03 → EL-07 → H-02 カメラ (XIAO) → I-03 音声会話 | Web UI・WiFi・ブリッジ |
