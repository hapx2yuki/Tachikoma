## 購入先の集約方針 (2026-07-30)

ユーザーからの明示要望:

> 具体的にどのサイトでどの商品を購入したら良いかを指定して教えてください。
> 可能な限り複数のサイトにまたがることは避けたいので、Amazonなどでまとめて
> 買えるなら多少高くなっても構わないので、まとめるようにしてください。

これを受け、8並列の調査エージェントで BOM.md 全36品目 (A-1〜A-5) + フィラメント
(A-6) + 工具一式 (B章) について Amazon.co.jp 上の該当商品を横断調査した
(調査日 2026-07-30)。方針は以下のとおり:

1. **Amazon.co.jp 一括購入を最優先**とする。商品タイトル (可能な場合は
   ページ本文) を WebFetch/ブラウザで照合し、BOM.md の仕様 (型番・寸法・
   定格・角度等) と一致することを確認できた商品を主購入先に採用する。
   価格が秋月電子/スイッチサイエンス/モノタロウ等の従来候補より高くなる
   場合でも、ユーザー方針により Amazon 側を優先する。
2. **Amazon で仕様一致を確認できなかった品目、または Amazon 上に該当商品が
   見つからなかった品目のみ、例外として従来の購入先 (秋月電子等) を維持
   する**。該当は僅少で、D-2 節に一覧化した (WS2812B、φ23-28mmスピーカー、
   φ1.1mmドリル刃、A-5 #18b M3×10なべ小ねじ、TPU95A[Bambu純正が必須の
   場合]の5件)。**[2026-07-30 レビュー指摘対応]** 旧版はここを「3件」、
   D-2節の完全性主張部分を「4件のみ」と記載しており内部で矛盾していた上、
   #18bのなべ小ねじがD-1・D-2いずれの一覧にも未掲載という実際の記載漏れが
   あった。本改訂でD-2になべ小ねじの行を追加し、件数表記を5件に統一した
   (詳細はD-2節・末尾検証節参照)。
3. 発注前のブラウザ目視確認が必要な項目 (JS描画で価格が自動取得できない
   もの、WebFetchでのタイトル照合が失敗し WebSearch スニペットのみに基づく
   もの) は、既存の規律どおり **UNVERIFIED** と明記し、確認済みとは書かない。
4. 既に Amazon 確定リンクだった品目 (DS3218MG・EMAX ES9251II・PCA9685・
   LiPo・UBEC・DC-DC・LiPo充電器・ピンバイスセット・ニッパー・小型バイス・

### B-3. Bambu Lab X2D 運用注意 (TPU/AMS)

X2Dで本設計の TPU 95A (`foot_pad`) を印刷する場合、**AMSでの直接給紙は
推奨されない**。Bambu Lab公式Wikiによれば、AMSに直接セット可能なのは
「AMS用TPU」(硬度が高くローディング要件の緩い専用グレード)のみで、
**硬度95A以下の一般的なTPU (95A HF/90A/85A) は送り出し抵抗が高いため
外部スプールホルダー (バイパス給紙) またはトップマウントスプールホルダー/
TPUフィードアシストモジュールの使用が必要**。特にTPU 95A HFは外部
スプールホルダーでの印刷が推奨されている。また右補助押出機(デュアルノズル
のサブノズル)はフィード抵抗が高くTPU印刷非対応のため、**TPUは必ず
メインノズル側で印刷すること** [出典: Bambu Lab公式Wiki
「X2D用TPU印刷ガイド」wiki.bambulab.com/ja/x2d/manual/tpu-printing-guide,
確認日2026-07-30]。**[2026-07-30追記]** A-6節のとおりAmazon調達のTPUは
第三者製 (OVERTURE) のためRFID自動認識非対応であり、上記のAMSバイパス
給紙の必要性はより強く該当する (自動認識が効かない分、パラメータ設定・
給紙経路とも手動確認が必須)。
